# 错误码表

前后端共用。前端按 `code` 决定提示文案，按 HTTP 状态决定是否需要跳登录。

## 通用

| code | HTTP | 含义 | 前端处理 |
|---|---|---|---|
| 0 | 200 | 成功 | 取 `data` |
| 400 | 400 | 参数不合法（字段格式、缺少必填） | 表单行内提示 |
| 401 | 401 | 未登录 / 令牌过期 | 清除本地令牌 → 跳登录 |
| 403 | 403 | 无权限（非管理员、账号被禁用） | 提示并留在当前页 |
| 404 | 404 | 资源不存在 | 提示 + 返回列表 |
| 409 | 409 | 状态冲突（重复签到、任务未完成就下载、已处理） | 提示当前状态 |
| 413 | 413 | 文件超过 10MB | 上传区提示 |
| 422 | 422 | 语义不合法（扫描版 PDF、语言对不支持、解析失败） | 提示原因 |
| 500 | 500 | 服务内部错误 | 通用「稍后重试」 |

## 业务码（与 HTTP 状态并行返回）

| code | 典型 HTTP | 含义 | 触发场景 |
|---|---|---|---|
| **3001** | 422 / 400 | **翻译引擎未接入** | 未填 API Key、密钥格式非法、引擎已停用、全书翻译失败 |
| **3002** | 402 | **积分不足** | 官方引擎预估消耗 > 当前余额 |
| **4001** | 400 | **PDF 需前端导出** | 请求 `download?format=pdf`；PDF 由结果页「打印 → 另存为 PDF」生成 |
| **5001** | 500 | 服务处理异常 | 管线内部错误，`message` 含可读原因 |

## 约定

1. **业务码不回退成 HTTP 200**：便于浏览器/网关按状态码做监控，前端仍以 `code` 为准
2. **`message` 一定是用户可读中文**，不暴露堆栈
3. 新增业务码必须同步更新本表与 `openapi.json` 的描述

## 前端映射示例

```js
const ERROR_MESSAGES = {
  3001: '翻译引擎未接入，请填写可用的 API Key',
  3002: '积分不足，请签到或获取积分后再试',
  4001: 'PDF 请使用「打印 / 另存为 PDF」导出',
  5001: '服务处理异常，请稍后重试'
}
```
